# Security Policy

Bastion is a control plane for AI agents' tools, so security reports are taken
seriously.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Use GitHub's private reporting instead:
[**Report a vulnerability**](https://github.com/SoumilBhandari/Bastion/security/advisories/new).

You can expect an acknowledgement within a few days, followed by updates on the
fix and disclosure timeline as it progresses.

## Supported versions

Bastion is pre-1.0 and under active development. Fixes are applied to the latest
commit on `main` and the most recent release.
