# Code of Conduct

The Bastion project adopts the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1 — a
widely used standard for open and welcoming open-source communities. The full
text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and constructive. Abusive or harassing behavior is not
tolerated, in project spaces or where someone is representing the project.

## Reporting

To report unacceptable behavior, contact the maintainer via GitHub —
[@SoumilBhandari](https://github.com/SoumilBhandari). Reports are handled
confidentially.
